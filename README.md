# My Budget Tracker

## Project Description

My Budget Tracker is a simple website for recording and displaying personal expenses.

## What I Built

### index.html
The HTML file contains:
- A Budget Tracker heading
- An Add Expense form
- Expense Name and Amount inputs
- A Category dropdown with five options
- An Add Expense button
- An expense table with five sample expenses
- An image
- A YouTube video
- A collapsible How to use this tracker section

### style.css
The CSS file contains:
- Table borders and spacing
- A colored table header
- Alternating table row colors
- A hover effect on table rows
- A focus effect on inputs
- A pointer cursor for the button
- Advanced CSS selectors

## Technologies Used

- HTML5
